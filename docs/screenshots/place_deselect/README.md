# 장소 선택 취소 시연 (demo/place-deselect)

배포 서버(`https://api.todait.co.kr`) 상대로 에뮬레이터(Medium_Phone_API_36.1, 1080x2400)에서
로그인부터 코스 저장 화면까지 실제 플로우로 돌린 캡처다.

| # | 캡처 | 확인 내용 |
|---|---|---|
| 01 | `01_compose_initial.png` | 코스 구성 진입. 안내 문구가 "장소를 눌러 담고, **다시 눌러 취소**할 수 있어요!" 로 바뀌었고 ✓ 는 비활성 |
| 02 | `02_two_selected.png` | 카페 2곳 담기 → 초록 테두리 + 지도 핀 3개, ✓ 활성. 같은 카테고리 2곳이 동시에 담긴다 |
| 03 | `03_deselected.png` | 담았던 카드를 **다시 탭해 취소** → 테두리 사라지고 지도 핀 3→2 |
| 04 | `04_other_category.png` | 맛집 탭으로 옮겨 1곳 추가 |
| 05 | `05_committed_ordering.png` | ✓ 로 일괄 커밋 후 순서 설정 화면. **취소한 장소는 서버에 올라가지 않았다**(선택한 장소 3) |
| 06 | `06_remove_blocked.png` | 커밋 뒤 `<` 로 돌아와 같은 카드를 탭 → "이미 코스에 담긴 장소예요" 안내(삭제 API 미배포로 인한 한계) |
| 07 | `07_course_save.png` | 코스 저장 화면 경로 미리보기에도 취소한 장소가 없다 |

02 는 부수적으로 **"카테고리당 1곳" 제약이 배포 서버에 없다**는 것도 보여준다(2026-08-16 API 실측과 일치).

07 에서 최종 저장은 누르지 않았다 — 임시 코스는 SAVING 상태로 남아 있다.
